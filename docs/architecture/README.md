# Arquitetura do redesign do LabMAES

Este diretório registra decisões arquiteturais estáveis do redesign do site do
Laboratório de Moda, Arte, Ensino e Sociedade (LabMAES).

## Convenção

- `adr/`: Architecture Decision Records — decisões que afetam a arquitetura e cuja
  alteração futura deve ser deliberada e registrada.
- `insumos-brainstorming/`: materiais exploratórios que deram origem às decisões.
  Não são fonte normativa da implementação.

## Ordem de precedência

Em caso de divergência:

1. ADR aceito;
2. spec aprovada da fase;
3. plan de implementação;
4. documentação operacional;
5. insumos de brainstorming.

## Estado do redesign

- Fase 0 — Arquitetura de informação e conteúdo: **concluída**, após aceitação dos
  ADRs 0001–0006 e da spec correspondente.
- Fase 1 — Content foundation: **em andamento**.
