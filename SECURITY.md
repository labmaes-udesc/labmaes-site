# Segurança e dados pessoais

## O que reportar

- vulnerabilidades no site, na configuração do Cloudflare ou nas dependências;
- **exposição de dados pessoais** no site ou no repositório (inclusive no histórico do Git):
  documentos, fotos, e-mails, telefones ou informações de saúde publicados sem necessidade
  ou sem consentimento;
- credenciais, tokens ou links privados (ex.: salas de videoconferência) publicados por engano.

## Como reportar

**Não abra issue pública**, porque ela tornaria o problema mais visível.

Escreva para **modaesociedade@gmail.com** com o assunto `[segurança] site LabMAES`,
informando o endereço ou o arquivo envolvido e, se possível, o commit. Se a opção estiver
habilitada no repositório, também é possível usar
[Report a vulnerability](../../security/advisories/new).

Respondemos em até 5 dias úteis. Casos de dados pessoais expostos são tratados com prioridade:
o conteúdo é removido do site e, quando necessário, do histórico do repositório.

## Versões cobertas

Apenas o site publicado a partir da branch `main`.
